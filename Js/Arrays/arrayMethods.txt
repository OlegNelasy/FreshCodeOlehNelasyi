1. Добавление и удаление элементов
Эти методы меняют сам массив.

push(item) — добавляет один или несколько элементов в конец массива.

pop() — удаляет последний элемент из массива и возвращает его.

unshift(item) — добавляет один или несколько элементов в начало массива.

shift() — удаляет первый элемент из массива и возвращает его.

splice(index, count, items...) — швейцарский нож для массивов. Может удалять, вставлять или заменять элементы в любом месте массива.

2. Создание новых массивов (оригинал не меняется)
slice(start, end) — копирует кусок массива (от индекса start до end) и возвращает как новый массив.

concat(arr1, arr2) — объединяет текущий массив с другими массивами или элементами в один новый массив.

3. Поиск в массиве
includes(item) — проверяет, есть ли элемент в массиве. Возвращает true (если нашел) или false (если нет).

indexOf(item) — ищет элемент и возвращает его индекс (порядковый номер). Если не нашел, вернет -1.

find(func) — находит и возвращает первый элемент, который подошел под условие в переданной функции.

findIndex(func) — работает как find, но возвращает не сам элемент, а его индекс.

4. Перебор и трансформация (самые мощные методы)
forEach(func) — просто выполняет переданную функцию для каждого элемента массива по очереди (например, чтобы вывести каждый элемент в консоль).

map(func) — берет каждый элемент, делает с ним что-то (согласно твоей функции) и собирает результаты в новый массив. (Например: умножить все числа массива на 2).

filter(func) — фильтрует массив. Создает новый массив, в который попадут только те элементы, которые прошли проверку условием. (Например: оставить только числа больше 10).

reduce(func, initial) — берет все элементы массива и "схлопывает" их в одно значение. Чаще всего используется, чтобы найти сумму всех чисел в массиве.

5. Сортировка и форматирование
sort() — сортирует элементы массива на месте (по умолчанию сортирует как текст, по алфавиту).

reverse() — переворачивает порядок элементов в массиве задом наперед.

join(str) — берет все элементы массива и склеивает их в одну большую текстовую строку, вставляя между ними указанный символ (например join(", ")).
